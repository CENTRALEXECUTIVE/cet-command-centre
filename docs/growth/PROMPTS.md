# Prompt library — copy, paste, go

Open Claude Code on the `cet-command-centre` repo and paste one of these. Each
names the agent so Claude hands the work to the right specialist. Drop any
exports into `docs/growth/data/` first (that folder is never committed).

## Google Ads (google-ads-strategist)
- "Use the google-ads-strategist. Walk me through setting up Google Ads conversion tracking in GTM for the cetBooking event, one screen at a time. I'm on a tablet."
- "Use the google-ads-strategist. Audit my account from the exports in docs/growth/data/. Give me the 10 changes ranked by money saved, then 'do these 3 first'."
- "Use the google-ads-strategist. Here's this week's search terms report. Give me negatives to add and new exact/phrase keywords, as an Ads Editor CSV."
- "Use the google-ads-strategist. Research the top 5 competitors' ads for 'sheffield to manchester airport taxi' and write me 3 RSAs that beat them. Count every character."
- "Use the google-ads-strategist. Build a corporate/business-travel campaign: keywords, negatives, 2 RSAs, sitelinks, callouts, budget."
- "Use the google-ads-strategist. Weekly review: what changed since last week's CHANGELOG, did it work, what next?"
