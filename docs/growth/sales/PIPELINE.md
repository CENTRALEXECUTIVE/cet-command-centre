## Status key
`new` → `email1-sent` → `fu1-sent` (day 4) → `fu2-sent` (day 10) → `linkedin-sent` →
`closed-no-reply` (day 21; leave for six months)
Replies: `replied` → `call-booked` → `rate-card-sent` → `trial-job` → `account-open` / `partner-live`
Exits: `not-now` (diary a date), `lost` (note the reason), `opted-out` (**never contact again**)
