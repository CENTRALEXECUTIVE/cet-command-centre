# ETO Styles → CET

ETO lets you set the web-booking **button/link colours** — Default and Active
states (Background, Border, Text), a Border radius, and a Custom CSS box.
(ETO values: background/border `#f4b41a`, text `#000000`, radius 6px.)

## CET today
- The public form `/book` and the widget are already styled in the **CET brand**
  in code — gold `#FBBA2A`, black, white, Inter, rounded corners. It already
  matches the marketing site.

| ETO control | CET | Rec | Notes |
|---|---|---|---|
| Button/link colours (default + active) | ✅ (in code) | Skip | Already on-brand; a colour-picker admin adds little for a single-brand firm. |
| Border radius | ✅ (in code) | Skip | |
| Custom CSS box | ❌ | Skip | Risky (lets bad CSS break the form); not needed. |

## Verdict
**Skip.** CET's booking pages are already brand-styled in code and match the
site. A colour/CSS admin is only useful for a white-label product serving many
firms — CET is one firm, so it's clutter. If Abdi ever wants a colour tweak, it's
a one-line change, no admin screen required.
