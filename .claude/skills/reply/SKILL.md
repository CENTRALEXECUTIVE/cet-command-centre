---
name: reply
description: Draft a fast, on-brand reply to a pasted customer/business email, WhatsApp, text, review or complaint for Central Executive Transfers. Use when the user says /reply or pastes a message asking how to respond.
---

Hand the pasted message (and any booking ref or price the user gave) to the
`customer-comms` agent. Return the ready-to-copy reply first, a WhatsApp-length
version if the original was a WhatsApp/text, then "Check before sending:" with
any gaps. Nothing is sent — the user copies it.

Email replies are SHORT (directors, 26 Nov 2026): see the REPLIES section of `docs/growth/sales/kit/house-email-style.md`. Hi [name], one thank-you line, the facts, one question, Kind regards, Matthew.
